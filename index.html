Comandos Importantes del Git y GitHub

git init: Para inicializar un proyecto en entorno Git dentro de tu Laptop

git add: para subir todos tus archivos a la base de datos Git, Como dato extra, al usar el git add . se sube todos tus archivos

git commit -m "...": se usa para subir tus cambios a Git, lo que hay dentro de las comillas es un mensaje que debes dejar como prueba de lo nuevo o el cambio que se hizo

git remote add origin "Url del repositorio": Sirve para crear un repositorio en la nube (GitHub) donde todos tus archivos esten en dicho servidor

git push: Sirve para subir tus archivos y cambios en la nube GitHub
